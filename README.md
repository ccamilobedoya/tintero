# Tintero

> Servidor de pantallas e-ink para ESP32: el servidor es el tintero y las pantallas, las hojas.

Proyecto en construcción, todavía privado. Diseño y decisiones: `docs/decisiones/`; fichas de trabajo: `docs/fichas/`; mapa del repo: `docs/MAPA.md`.

Primeros pasos en una copia nueva:

```bash
npm ci && npm run setup   # dependencias + hook de git
tools/revisar             # revisión completa
```
