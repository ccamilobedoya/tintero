# ADR-0013 · El firmware lo escribe el dueño

- **Estado:** aceptada
- **Fecha:** 2026-10-21 · **Decidió:** dueño del proyecto

## Contexto
El dueño quiere escribir el firmware del ESP32 él mismo, para aprender.

## Decisión
El firmware lo escribe el dueño. Los agentes hacen servidor, emulador y pruebas, y ayudan con el firmware solo si él lo pide.

## Consecuencias
El emulador fija el contrato que el firmware debe cumplir.
