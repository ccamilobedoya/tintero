# ADR-0010 · Primeras tareas en Trilium (tablero Kanban)

- **Estado:** aceptada
- **Fecha:** 2026-10-21 · **Decidió:** dueño del proyecto

## Contexto
Hace falta una fuente de tareas editable que el servidor ya pueda leer.

## Decisión
Las primeras tareas viven en un tablero Kanban de Trilium. Los atributos de cada tarjeta se deciden con los diseños. Otra integración con funciones extra llega después.

## Consecuencias
Trilium es de un solo usuario: las tareas de otras personas llegan con otra integración.
