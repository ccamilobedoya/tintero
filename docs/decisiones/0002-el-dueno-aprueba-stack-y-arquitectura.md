# ADR-0002 · El dueño aprueba stack, arquitectura y tecnologías

- **Estado:** aceptada
- **Fecha:** 2026-10-21 · **Decidió:** dueño del proyecto

## Contexto
El arquitecto (Claude) propone; el dueño quiere decidir.

## Decisión
Toda decisión de stack, arquitectura o tecnología necesita el ok explícito del dueño. Lo demás se marca «propuesta». La documentación vive en Trilium.

## Consecuencias
Las fichas no avanzan sobre propuestas sin aprobar.
