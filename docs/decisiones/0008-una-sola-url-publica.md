# ADR-0008 · Una sola URL pública

- **Estado:** aceptada
- **Fecha:** 2026-10-21 · **Decidió:** dueño del proyecto

## Contexto
Evitar problemas con IP locales que el router no controla.

## Decisión
Todas las pantallas usan la URL pública, también en casa.

## Consecuencias
Sin internet, la pantalla de la casa no se actualiza.
