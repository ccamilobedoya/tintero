# ADR-0014 · Nombre: Tintero

- **Estado:** aceptada
- **Fecha:** 2026-10-21 · **Decidió:** dueño del proyecto

## Contexto
Hacía falta un nombre corto, en español.

## Decisión
El proyecto se llama Tintero: el servidor es el tintero y las pantallas, las hojas.

## Consecuencias
Libre en PyPI; en GitHub hay proyectos pequeños y una app de Flathub con ese nombre.
